## 📂 Projetos

### 📊 Amostragem Estratificada
Comparação entre três métodos de alocação de amostra — **alocação proporcional**, **alocação uniforme** e **alocação de Neyman** — aplicados a dados reais do **DataSUS**.

O projeto avalia como cada estratégia de alocação impacta a precisão das estimativas amostrais, discutindo em quais cenários cada método se mostra mais eficiente.

🔗 [Acessar projeto](./Amostragem%20estratificada)

---

### 🚀 Predição de Lucro de Startups
Avaliação comparativa entre **regressão linear múltipla** e **modelos de aprendizado de máquina** para prever o lucro de startups a partir de variáveis financeiras e operacionais.

O projeto compara desempenho, interpretabilidade e trade-offs entre a abordagem estatística clássica e técnicas de machine learning.

🔗 [Acessar projeto](./Predição%20de%20lucro%20de%20startups)
